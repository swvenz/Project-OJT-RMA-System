OJT Management System

Project overview:

The OJT Management System is designed to manage and monitor the internship process of students. It provides a centralized platform where students, academic supervisors, company supervisors, administrators, and OJT coordinators can perform their respective responsibilities.

Prerequisites:
- PostgreSQL database server
- The selected programming language and its required environment
- A code editor or development environment
- Git for repository management
  
Installation steps:
1. Download or clone the project repository.
2. Install the required application dependencies.
3. Create a PostgreSQL database named ojt_managementdb.
4. Configure the database connection using the .env file.
5. Execute the SQL migration script to create the database tables.
6. Execute the sample seed script to insert initial testing records.
7. Start the application using the instructions for the selected framework.
8. Open the application and test the available functions.
