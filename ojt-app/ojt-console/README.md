# OJT Management System (desktop app)
Java 17, Maven, JDBC, PostgreSQL, Swing window UI. Uses the existing OJT_Managementdb tables (nothing is created or altered).
1. Check src/main/resources/db.properties (url, user, password).
2. In this folder run: mvn -q compile exec:java
